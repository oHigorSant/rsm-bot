# RSM — Teste de Animação de Robô

Experimento de animação para o site da RSM, explorando animação CSS combinada com GIF para criar um personagem interativo na página.

## Visualizar

[ohigorsant.github.io/rsm-bot](https://ohigorsant.github.io/rsm-bot/)

## O que foi testado

- Animação de um personagem robô usando GIF
- Sincronização de efeitos CSS com o ciclo do GIF
- Integração em página HTML simples

## Tecnologias

- HTML, CSS e JavaScript
